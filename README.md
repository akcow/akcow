## 关于我

我叫王尉人，广东工业大学计算机科学与技术专业大三学生，目前在补基础，准备考研。

我报这个专业是因为家里人说计算机好就业，当时没想那么多。让我真正留下来的是大二下学期的一次救火：工作室接了个项目，前端缺人，而我对小程序开发是零基础，连 WXML 和 HTML 的区别都说不清。我用一周从零交付上线。那次之后我确认了一件事：我在信息不完整、时间不够、没人带的混乱场景里是兴奋的。

## 我的底线

1. 代码自己敲。可以看文档看教程，最后的代码必须是我一个字符一个字符写出来的
2. 引用必注明
3. 数据不造假。运行截图、测试结果、PSP 表格里的每个数字都是真跑出来的
4. AI 可以用，但要声明并逐行读懂，不用它生成整篇博客或核心逻辑冒充自己的产出
5. 不抄往届作业
6. 按时提交，不卡点

## 关于"快速上手"这件事

我一度以为上手快是天赋。读了《构建之法》3.4 节"技能的反面"之后开始怀疑：如果专家靠的是模式识别，而模式是领域特定的，那我的"快速上手"是不是只是"我见过类似的东西"？

我还没想清楚。打算这样验证：每次上手新技术，先写 200 行最丑的原型，然后写一份"我原本以为 X，实际是 Y"的笔记。半年后这些笔记如果能拼出一个可复述的方法，那它就是真的；不能，那就是错觉，我得换条路。
